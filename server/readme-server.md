# Report Generator Server

Инструкция по запуску и использованию REST API для `report-generator`.

Запуск:

1. Установите зависимости в папке `server`:

```
cd server
npm install
```

2. Запустить сервер:

```
node report-generator.js
```

По умолчанию сервер слушает `http://localhost:3000`.

Эндпоинты:

- `GET /files` — список загруженных входных файлов (только `.xlsx`).

- `POST /files` — загрузка файлов (multipart/form-data). Поле формы: `files` (можно несколько).
  - Только файлы с расширением `.xlsx` сохраняются в `server/input`.

- `DELETE /files/:name` — удалить входной файл по имени.

- `POST /generate` — сгенерировать итоговый файл. Ожидает JSON body с полями:
  - `files` (optional): массив имён входных файлов из `server/input`. Если не указан — используются все файлы.
  - `resultName` (optional): имя результирующего файла (по умолчанию `Акруалы за <текущий_месяц>.xlsx`).
  - `titleFontSize` (optional): размер шрифта заголовка таблицы (по умолчанию `11`).
  - `cellFontSize` (optional): размер шрифта остальных ячеек (по умолчанию `11`).

  Если генерация проходит успешно сервер возвращает файл для скачивания и после успешной отправки удаляет использованные входные файлы.
  Если произошла ошибка — возвращается код 500 с текстом ошибки, входные файлы не удаляются.

- `GET /result/:name` — скачать существующий результирующий файл из `server/output`.

- `DELETE /result/:name` — удалить результирующий файл из `server/output`.

- `DELETE /cleanup` — удалить все файлы в `server/input` и `server/output`.

Примечания:

- Папки `server/input` и `server/output` создаются автоматически при запуске сервера, если их нет.
- Для загрузки файлов с клиента используйте `multipart/form-data` на `POST /files`.
- После успешного `POST /generate` использованные входные файлы будут удалены — делайте бэкап при необходимости.
